# SORTING ALGORITHMS

Sorting is the process of rearranging items in a collection(e.g an array) so that the items are in some kind of order.

There are many forms of sorting algorithms and each of them works differently to achieve the same result.

They include:

1. Bubble sort
2. Insertion Sort
3. Selection Sort
4. Radix Sort
5. Merge Sort
6. Quick Sort


### Why learn sorting algorithms?
1. Sorting is an incredibly common task, so it's good to know how it works.
2. There are many different ways to sort things , and different techniques have their own pros and cons.

### Built-In Javascript Sorting

The default sort order is according to Unicode code points.

### Example

```javascript
var months = ["March", "Jan", "Feb", "Dec"];
months.sort();
console.log(months)
// expected output: Array ["Dec", "Feb", "Jan", "March"]

var array1 = [1, 30, 4, 21];
array1.sort();
console.log(array1);
// expected output: Array [1, 21, 30, 4]
```

We can however specify to javascript how we want the items to be sorted. This can be done by specifying the order.

### Example

```javascript
var array1 = [1, 30, 4, 21];
array1.sort((a,b) => a-b);
console.log(array1);
// expected output: Array [1, 4, 21, 30,]
```
